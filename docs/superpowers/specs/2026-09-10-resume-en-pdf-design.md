# Английская версия резюме и сборка PDF из разметки

Дата: 2026-09-10
Репозиторий: [aznaur-arkelov/resume](https://github.com/aznaur-arkelov/resume)

## Зачем

Репозиторий обслуживает активный поиск работы: ссылку получают рекрутеры, PDF уходит в отклики. Отсюда три требования — актуальность, презентабельность и наличие английской версии.

Из трёх названных проблем (нет английской версии, нет акцента под вакансию, внешний вид) вторая снимается решением обойтись **одним сильным вариантом на каждом языке**. Плодить версии под роли не требуется, поэтому конвейер «данные плюс шаблоны» не строим — для двух документов это решение несуществующей задачи.

## Область работ

**Входит:**

- английская версия резюме `README.en.md`;
- переключатель языков между двумя README;
- скрипт сборки PDF из разметки;
- английский PDF, собранный этим скриптом;
- разбивка плотного сводного абзаца в обеих версиях.

**Не входит:**

- GitHub Pages — рассматривался как вариант Б, отложен до момента, когда содержимое будет вычищено;
- варианты резюме под отдельные роли;
- переработка достижений: они оцифрованы (20+ дашбордов, 50+ пользователей, −70% трудозатрат) и в правке не нуждаются;
- автоматическая пересборка PDF в CI — сборка запускается вручную при изменении резюме.

## Артефакты

| Файл | Язык | Телефон | Происхождение |
|---|---|---|---|
| `README.md` | русский | нет | существует, правится |
| `README.en.md` | английский | нет | создаётся |
| `Arkelov.pdf` | русский | есть | существует, **не трогаем на первом этапе** |
| `Arkelov_en.pdf` | английский | есть | собирается скриптом |

## Конвейер сборки

```
README.{md,en.md} → markdown в HTML → HTML + CSS → Chrome headless --print-to-pdf → PDF
```

Решение продиктовано окружением: `pandoc`, `wkhtmltopdf`, `weasyprint` и LaTeX на машине отсутствуют, а Chrome и Edge установлены. Печать через headless-браузер не требует установок, отображает кириллицу на системных шрифтах и позволяет управлять вёрсткой обычным CSS. LaTeX-вывод по умолчанию выглядит как научная статья, что для резюме неуместно.

Состав:

- `build/render.js` — Node-скрипт: читает разметку, преобразует в HTML, подставляет шаблон и контакты, вызывает Chrome в headless-режиме;
- `build/resume.css` — стили печатной версии;
- `build/template.html` — каркас страницы;
- `package.json` — единственная зависимость `marked`, команда `build:pdf`; в репозитории его сейчас нет, создаётся в рамках работ;
- `.gitignore` — тоже создаётся, скрывает `build/contacts.local.json` и `node_modules/`.

## Контакты и телефон

Телефон присутствует в PDF и отсутствует в README — решение принято ранее и остаётся в силе.

Механика: контактный блок для печати хранится в `build/contacts.local.json`, файл внесён в `.gitignore`. Скрипт подставляет его в шапку при сборке. Публичная разметка остаётся без номера, поведение совпадает с нынешним.

Английский PDF получает телефон по умолчанию — он выполняет ту же роль в откликах, что и русский. Изменение этого поведения стоит одной строки в конфигурации.

## Ограничение одной страницы

Существующий PDF укладывается в один лист при полном совпадении содержимого с README. Сгенерированные версии обязаны укладываться так же.

Английский текст в среднем на 5-10% длиннее русского при равном содержании, поэтому запас закладывается сразу: базовые размеры шрифта и межстрочных интервалов подбираются по английской версии как по худшему случаю.

## Перевод

Перевод смысловой, не дословный. Согласованные соответствия:

| Русский | Английский |
|---|---|
| судоходный дивизион | shipping division |
| витрины | data marts |
| self-service аналитика | self-service analytics |
| дерево метрик | KPI framework |
| фрахтовые ставки | freight rates |
| Русал | RUSAL |

Черновик готовит Claude, вычитку выполняет владелец резюме. Резюме — документ, где неточная формулировка стоит собеседования, а уровень B2 достаточен для оценки.

## Стратегия замены русского PDF

Существующий `Arkelov.pdf` свёрстан во внешнем инструменте с ручной доводкой. Первая версия CSS-генератора с высокой вероятностью окажется хуже, и доведение потребует итераций.

Поэтому порядок такой:

1. английский PDF собирается новым конвейером — сравнивать его не с чем;
2. русский PDF собирается тем же конвейером **рядом**, во временный файл;
3. владелец сравнивает временный файл с существующим;
4. замена происходит только при явном одобрении.

При отказе от замены английский остаётся единственным сгенерированным, существующий русский сохраняется без изменений. Этот исход считается допустимым, а не провалом.

## Критерии готовности

- `README.en.md` существует, вычитан владельцем, структурно совпадает с русской версией;
- в обеих версиях есть работающий переключатель языков;
- `npm run build:pdf` собирает PDF из обеих версий без ручных действий;
- английский PDF укладывается в одну страницу и содержит телефон;
- `build/contacts.local.json` отсутствует в индексе git;
- существующий `Arkelov.pdf` не изменён без отдельного одобрения.
